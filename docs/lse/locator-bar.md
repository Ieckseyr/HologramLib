# 方位条（locatorBar*）

!!! warning "当前没有可用的实现"
    方位条这一组接口**暂时移除**，文档站只保留说明。

## 为什么做不了

客户端的方位条不是普通的 HUD，而是"玩家方位"系统的一部分：

- 它只在**有真实玩家**参与时才会出现；服务端没有真实玩家时，这条 HUD 根本不画
- 自建航点必须锚定到客户端认识的实体（真实玩家 / 已下发的假玩家 / 生物），否则没有可对齐的对象
- 想走原生路径，需要构造 `ServerWaypoint` / `ServerWaypointGroup` 并注册进玩家的方位组，
  但这两个类的构造函数没有导出，`Waypoint::mWorldPos` 的 `WorldPosition` 也禁止构造

也就是说：**目前在插件层没有可靠的办法创建"客户端认的"锚点**。协议包发得出去（字段、编码、回读校验都正常），
客户端就是不渲染。
